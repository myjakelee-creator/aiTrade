## 2. 모델 목적

`순매수 강도` 모델은 장중 필터 통과 종목 전체를 대상으로 다음 항목을 점수화해서 총점이 높은 종목부터 줄을 세운다.

```text
순위 + 전일 순위 상승 + 거래대금/전일 거래대금 + 잔량비 + 순간강도 + 장중 1분강도 + 프로그램/거래대금
```

장마감에는 실시간 1분강도가 독립 신호가 아니므로 1분강도 항목을 계산에서 제외하고, 5분강도는 참고값으로만 표시한다.

## 3. 전체 구조

| 구분 | 장중 | 장마감 |
|---|---:|---:|
| 계산 항목 수 | 7개 | 6개 |
| 총점 분모 | 700점 | 600점 |
| 1분강도 | 실시간 1분강도 상승값 계산 포함 | 계산 제외 |
| 5분강도 | 필요 시 참고 | 표시 전용 |
| 등급 표시 | `round(총점 / 700 × 100)` | `round(총점 / 600 × 100)` |

핵심 원칙:

```text
장중 700점, 장마감 600점 이원화.
백분율 점수와 A/B/C/D/F 등급은 현재 사용 가능한 계산 분모를 기준으로 산출한다.
```

## 4. Pool 배치와 갱신 속도

전체 종목을 `순매수 강도 백분율 점수` 기준으로 한 번 줄 세운 뒤, 순위에 따라 각 Pool에 배치한다.

| 순매수 강도 순위 | 표시 Pool | 갱신 Lane | 의미 |
|---:|---|---|---|
| 1~5위 | Top5 | HOT | 최우선 후보 |
| 6~20위 | Top15 | HOT | 집중 관찰 |
| 21~50위 | Top30 | MID | 후보 확장군 |
| 51위 이하 | Top300 Pool | POOL | 전체 감시군 |

```text
점수로 전체 줄세우기 → Pool 배치 → Pool에 따라 데이터 갱신 속도 결정
```

## 5. 점수 항목 최종안

| 번호 | 항목 | 장중 점수 | 장마감 점수 | 비고 |
|---:|---|---:|---:|---|
| 1 | 순위 | 100 | 100 | 필터 통과 N개 기준 100~0점 비례 배점 |
| 2 | 전일 | 100 | 100 | `min(max(prev_rank-rank,0),100)` |
| 3 | 금액(억) | 100 | 100 | `trade_value_eok / prev_trade_value_eok` 비율 줄세우기 |
| 4 | 잔량비 | 100 | 100 | `ask_volume / (bid_volume + ask_volume) × 100` |
| 5 | 순간강도 | 100 | 100 | 체결강도 0~200을 0~100점 환산 |
| 6 | 1분강도 | 100 | 0 | 장중 실시간 1분값만 계산, 장마감은 계산 제외 |
| 7 | 프로(억) | 100 | 100 | 프로그램 순매수/거래대금 비율 줄세우기, 순매수 0 이하는 0점 |

---

## 6. 항목별 계산식

| 항목 | 계산식 | 비고 |
|---|---|---|
| 순위 점수 | `100 × (N - 현재순위) / (N - 1)` | N=1이면 100점 |
| 전일 점수 | `min(max(전일순위 - 현재순위, 0), 100)` | 100점 상한 필수 |
| 금액 점수 | `오늘 거래대금 / 전일 거래대금` 비율로 줄세운 뒤 100~0점 | 전일 거래대금 없으면 fallback 정책 적용 |
| 잔량비 점수 | `매도잔량 / (매수잔량 + 매도잔량) × 100` | 매도잔량 비율이 높을수록 점수 높음 |
| 순간강도 점수 | `min(max(체결강도, 0), 200) / 200 × 100` | 200 이상은 100점 |
| 1분강도 점수 | 장중: `one_min_strength_growth_rate` 또는 `one_min_strength_delta` 줄세우기 | 장마감에는 계산 제외, 5분강도는 표시 전용 |
| 프로 점수 | `프로그램 순매수 / 거래대금` 비율로 줄세운 뒤 100~0점 | 프로그램 순매수 <= 0이면 0점 |
| 등급점수 | `round(score_total_points / score_possible_points × 100)` | 장중 분모 700, 장마감 분모 600 |

## 8. 1분강도 장중/장마감 정책

| 구분 | 원천 | 계산 반영 | 상태 표시 |
|---|---|---:|---|
| 장중 | `one_min_strength_growth_rate` 우선, 없으면 `one_min_strength_delta` | 100점 항목 | `ok` |
| 장중 실시간 1분값 없음 | 없음 | 중립 50점, 분모 700 유지 | `fallback` |
| 장마감 / 실시간 1분값 없음 | `strength_5m` | 0점, 분모에서 제외 | `display_only` |
| 장마감 5분강도도 없음 | 없음 | 0점, 분모에서 제외 | `display_missing` |

```text
장마감에는 5분강도를 화면과 툴팁에는 보여주되, 총점 계산에서 제외한다.
따라서 장마감 총점 분모는 600점이고, 백분율 점수는 600점 기준으로 산출한다.
```

## 9. 전일 거래대금 확보 정책

| 단계 | 처리 | 결과 |
|---:|---|---|
| 1 | 재접속/서버 시작 시 전일 거래대금 TR 조회 | 가장 우선 |
| 2 | TR 성공 시 runtime cache 저장 | 재접속 시 즉시 사용 |
| 3 | TR 실패 but cache 있음 | cache 사용 |
| 4 | 전일 거래대금 직접값 없음 | 전일 종가 × 전일 거래량으로 계산 |
| 5 | 전일이 휴일/거래정지 등으로 부적합 | 마지막 유효 거래일 거래대금 사용 |
| 6 | 모든 방법 실패 | 금액 항목 60점 고정 fallback |
| 7 | fallback 사용 시 | 화면/툴팁에 `전일대금 미확인 60점` 표시 |

```text
전일 거래대금 missing을 0으로 저장하지 않는다.
최종 실패 시 0점이 아니라 60점 고정 fallback을 사용한다.
단, 화면에는 반드시 미확인 표시를 붙인다.
```
